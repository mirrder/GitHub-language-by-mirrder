# GitHub от майррдера (RU VERSION!!!!!)

Правильный русский перевод для GitHub, созданный для настоящих ситхов и уставших разработчиков. 

## 🛠 Что это меняет?
Официальный перевод GitHub слишком скучный. Этот скрипт возвращает интерфейсу былую суть:
* **Code** → Каракули
* **Commit** → Иди отдохни
* **Gists** → Глисты
* **Settings** → Завод
* **Sign out** → Стать ситхом
* **Accessibility** → Ослепнем вместе
* **New repository** → Создать велосипед без колёс
* **Fork** → Сделать копию (украсть)
* **Enterprise** → Попробовать sex 9 people (all man)
* и другие...

## 📥 Как установить (Инструкция)

Для того чтобы скрипт работал, вам нужно установить специальное расширение для браузера (менеджер скриптов). Это безопасно и бесплатно.

### Шаг 1: Установите Tampermonkey
*   **Для Chrome / Yandex / Edge / Opera:** Зайдите в магазин расширений вашего браузера и установите [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) (или [Violentmonkey](https://violentmonkey.github.io/)).
*   **Для Firefox:** Установите [Tampermonkey](https://addons.mozilla.org/ru/firefox/addon/tampermonkey/).
*   *На мобильных телефонах (Android) это работает в браузере Kiwi или Firefox с поддержкой дополнений.*

### Шаг 2: Установите скрипт
1. В этом репозитории нажмите на файл **`ru-version.user.js`**.
2. В правом верхнем углу нажмите кнопку **«Raw»** (Сырой код).
3. Откроется страница с кодом. Расширение Tampermonkey само перехватит её и покажет окно установки.
4. Нажмите кнопку **«Установить»** (Install).

### Шаг 3: Проверьте
Зайдите на главную страницу GitHub и обновите её (F5). 
Вместо привычных кнопок вы увидите:
* Вместо `Settings` — **Завод**.
* Вместо `Sign out` — **Стать ситхом**.

## ⚠️ Важное предупреждение (Дисклеймер)
Скрипт **не крадет ваши данные** и не ломает GitHub. Он просто заменяет текст на странице (работает через DOM). Ваши пароли и код в безопасности. 
Но помните: если вы нажмете **«Стать ситхом»** (Log out), вы действительно выйдете из аккаунта. Не пугайтесь.
